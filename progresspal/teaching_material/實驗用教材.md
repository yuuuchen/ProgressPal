# 1 堆疊與佇列
## 1-1 堆疊 (Stack)
### 1-1-1 定義與核心特性
- 堆疊是一種 **後進先出 (Last In First Out, LIFO)** 的線性資料結構。
- 操作點：僅限於「頂端 (Top)」進行存取。
- 典型比喻：一疊書、一疊磁碟或洗好的盤子，最後放上去的必須最先被拿走。
- 常見錯誤：堆疊溢位 (Stack Overflow)，通常發生在遞迴過深（導致 Call Stack 用盡）或記憶體配置耗盡時。
### 1-1-2 核心操作 (ADT)
- **Push**：將新元素加入堆疊頂端。
- **Pop**：移除並回傳堆疊頂端元素。
- **Peek**：回傳堆疊頂端元素但不移除它。
- **isEmpty**：檢查堆疊是否為空。
- **Size**：回傳堆疊中元素個數。
### 1-1-3 Python 實作與封裝
```python
class Stack:
    def __init__(self):
        self.items = [] # 底層使用動態陣列
        
    def push(self, item):
        self.items.append(item)
        
    def pop(self):
        # 實務上需檢查是否為空以避免 IndexError
        return self.items.pop() if not self.is_empty() else "Empty"
        
    def is_empty(self):
        return len(self.items) == 0

    def peek(self):
        return self.items[-1] if not self.is_empty() else None
```
### 1-1-4 實務應用
- **函式呼叫堆疊 (Call Stack)**：OS 用來儲存區域變數與遞迴回傳位址。
- **深度優先搜尋 (DFS)**：在圖形演算法中，利用堆疊記錄路徑，不斷往深處探索，直到無路可走再回溯。
- **Undo/Redo (撤銷/重做)**：編輯器會維護兩個堆疊來追蹤操作歷史。
- **語法分析**：如編譯器檢查 (), [], {} 是否成對匹配。
## 1-2 佇列 (Queue)
### 1-2-1 定義與核心特性
- 佇列是一種**先進先出 (First In First Out, FIFO)**的線性資料結構。
- 操作點：兩端存取。於「**隊尾 (Rear)**」新增元素，於「**隊首 (Front)**」移除元素。
- 典型比喻：超市結帳排隊、印表機待列印文件。
- 效能警告：在 Python 中使用 list.pop(0) 的時間複雜度為 $O(n)$，因為後方所有元素都需前移，這在處理大數據時是效能自殺。
### 1-2-2 核心操作
- **Enqueue**: 在隊尾加入元素。
- **Dequeue**: 在隊首移除元素。
- **Front/Peek**: 觀察目前隊首元素。
### 1-2-3 進階變體與實作
在系統設計中，為了達成 $O(1)$ 的 Dequeue 效能，應優先選擇 鏈結串列 (Linked List) 或 Python 內建的 collections.deque。
1. 鏈結串列實作 (高效版)
```python
class Node:
    def __init__(self, data):
        self.data = data
        self.next = None

class Queue:
    def __init__(self):
        self.front = self.rear = None
        
    def enqueue(self, item):
        new_node = Node(item)
        if self.rear is None:
            self.front = self.rear = new_node
            return
        self.rear.next = new_node
        self.rear = new_node
        
    def dequeue(self):
        if self.front is None: return "Queue is empty"
        temp = self.front
        self.front = temp.next
        if self.front is None: self.rear = None
        return temp.data
```
2. 常見進階變體
- **優先佇列 (Priority Queue)**：依據「權重」而非時間決定順序（如醫院急診、CPU 高優先級任務）。
- **雙端佇列 (Deque)**：允許在兩端同時進行新增與刪除。
### 1-2-4 實務應用
- **資源排程**：作業系統分配 CPU 時間（First-Come-First-Serve）。
- **緩衝區 (Buffer)**：網路封包處理、IO 資料暫存（如影音串流緩衝）。
- **廣度優先搜尋 (BFS)**：利用佇列按「距離層次」由近到遠地探索節點。
